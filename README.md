# ガムトークジェネレータ
会話に使えるワードやフレーズを提供するアプリ

https://gumtalk-generator.vercel.app/

## 開発・メンテナンス方針

### 依存関係管理 (Dependabot)
本プロジェクトでは GitHub Dependabot を利用して依存パッケージの自動更新およびセキュリティアラートのチェックを行っています。

- **設定ファイル**: [dependabot.yml](file:///Users/d-wtnbe/Documents/develop/gumtalk-generator/.github/dependabot.yml)
- **更新サイクル**: 毎週月曜日（Weekly）
- **対象エコシステム**: `npm` (pnpm), `github-actions`
